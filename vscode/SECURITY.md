# Security policy

## Report a vulnerability

Report a vulnerability privately, through GitHub's private vulnerability reporting on [JairJosafath/cel-lens](https://github.com/JairJosafath/cel-lens/security/advisories/new). Never report one in a public issue.

## What to expect

- We acknowledge your report within 7 days.
- Within 14 days we tell you whether it is a vulnerability and when a fix ships.

## Fixes

A fix ships as a patch release of the extension. When the engine (`cel-lens-core`) is affected, the release also carries a new engine pin. The CHANGELOG names the advisory.
